# マイルストーン

順に進める。各マイルストーンは「完了条件」をすべて満たし、`npm test` と `npm run typecheck` が通ってから次へ。
各マイルストーンの終わりに `docs/decisions.md` の「実装中の判断」を見直す。

## M0 足場

- Vite + TypeScript（strict, `noUncheckedIndexedAccess`）+ Vitest。`npm run dev/test/typecheck/build/preview`。
- `#stage` 240×400 のスケーリング（UI-01, 02）、ピクセルフォント同梱（UI-03）、タッチ用 CSS（UI-05）。
- `src/core/rng.ts`: シード付き乱数（xoshiro128** か mulberry32）、状態の保存と復元、ダイス記法 `"2d10"`, `"1d8+2"`, `"3d6-1"` のパーサ。
- `src/core/data/`: `data/*.json` の読み込みと検証（`loadGameData`）。不正なら起動時にエラー画面。
- 完了条件: 実機（iOS Safari / Android Chrome）でステージが整数倍で表示され、フォントが出る。乱数とダイスのテストがある（同じシードで同じ列、ダイス記法の境界値）。

     - 両経路の宝箱: ドロップの箱（戦闘の結果の後に操作が出る）と、セルの箱（線画と地図の印、乗ると操作、放っておいて踏み直すとまた出る、開けると印が消える）。
     - 8 種の罠: `debug.chest{trapId}` で各種を出して作動させる（毒・麻痺の表示、SAN −8、警報の戦闘と箱の戻り、転移）。
     - 転移後の地図: 転移の前後の探索済みの区画が離れて描かれ、続けて歩くと地図がつながる。
     - 衝動で開けてしまう流れ: 既定の編成で箱を見つける → 行動者の印 → 制止の箱 → 失敗なら罠を受けて開けてしまう。成功なら選択へ。
     - 職業の掛け合い: 盗賊 2 人で箱を見つけ、掛け合いの判定の箱に両者の内訳（素早さ・運・1d6・合計）、負けた方の SAN −1、担当の調べるの行に +10、担当の失敗で SAN −3。
     - 調べるの伏せた箱（U-2）と、解除の失敗で作動しないときの再挑戦（U-4）。
     - リロード（箱の選択中・警報の戦闘中）で同じ箱に戻る。演出スキップ ON で待ちが無い（HOLD の箱のタップだけ残る）。

     - 衝動の発生率: イベントごと（#1 の後）と宝箱あたり（#9 の後）。宝箱あたりの目安は既定の編成で 30% 以下で、超えていれば報告して止まる（U-5）。
     - 宝箱の作動回数（罠の種類別）と罠による死者、掛け合いの発生と担当の失敗の回数。
