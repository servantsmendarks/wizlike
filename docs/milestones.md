# マイルストーン

順に進める。各マイルストーンは「完了条件」をすべて満たし、`npm test` と `npm run typecheck` が通ってから次へ。
各マイルストーンの終わりに `docs/decisions.md` の「実装中の判断」を見直す。

## M0 足場

- Vite + TypeScript（strict, `noUncheckedIndexedAccess`）+ Vitest。`npm run dev/test/typecheck/build/preview`。
- `#stage` 240×400 のスケーリング（UI-01, 02）、ピクセルフォント同梱（UI-03）、タッチ用 CSS（UI-05）。
- `src/core/rng.ts`: シード付き乱数（xoshiro128** か mulberry32）、状態の保存と復元、ダイス記法 `"2d10"`, `"1d8+2"`, `"3d6-1"` のパーサ。
- `src/core/data/`: `data/*.json` の読み込みと検証（`loadGameData`）。不正なら起動時にエラー画面。
- 完了条件: 実機（iOS Safari / Android Chrome）でステージが整数倍で表示され、フォントが出る。乱数とダイスのテストがある（同じシードで同じ列、ダイス記法の境界値）。

## M1 コアの骨格

- `types.ts`（CLAUDE.md §5）、`engine.ts` の `execute` と画面遷移（title → creation → town）。
- `rules/creation.ts`: 簡易作成（CH-05）。`config.prototypeParty` から 6 人を作り、名前と性格だけ差し替える。リーダーは `personality: null`。
- `rules/growth.ts`: 必要経験値（CH-64）、レベルアップ（CH-61, 65）、レベルダウン（CH-62）、`maxLevelReached`（CH-63）。
- `rules/learning.ts`: 習得判定（MG-20〜25）。
- `rules/san.ts`: 増減と閾値（CH-50〜54）。
- 完了条件: 上記ルールの ID を名前に含むテストがある。`execute` が引数の state を書き換えないテストがある。

## M2 ダンジョン

- `rules/dungeon-gen.ts`: 生成（DG-04〜06）。到達性と辺の整合性のテスト（複数シードでループ）。
- `rules/dungeon.ts`: 移動・旋回・扉（DG-10）、視野 `visibleCells`（DG-12）、オートマップ（DG-13）、階段（DG-14）、罠（DG-20, 21、`pit` と `spinner` のみ）。
- 表示層: 線画ビュー（UI-20〜23）、マップ画面（UI-24）、スワイプと矢印ボタンとキーボード（UI-30〜35）、メッセージ窓（UI-43）。
- 遭遇判定（CB-01）は「遭遇した」メッセージを出すだけの仮実装でよい（戦闘は M3）。
- 完了条件: 実機で 2 階分を歩き、扉を抜け、階段を降り、マップが埋まる。スワイプの閾値と長押し間隔を設定から変えられる。

## M3 戦闘

- `rules/combat.ts`: 遭遇編成（CB-03〜06）、ラウンド（CB-10〜16）、命中とダメージ（CB-20〜25）、状態異常と SAN 攻撃（CB-30〜33）、オート（CB-40〜45）、逃走・勝利（CB-50, 51）、全滅の検出（CB-53）。宝箱（CB-52）は「罠なし・中身は金」の仮実装でよい。
- 表示層: 戦闘画面（UI-54）、`playback.ts`（UI-41, 42）、ダイス表示（UI-40）。敵の絵は無ければ色付き矩形。
- 呪文はプロトタイプの 2 つ（`fire_arrow`, `heal`）が戦闘で使えること。
- 完了条件: `data/monsters.json` の 6 種と戦える。前衛後衛と `ranged` のルール（CB-13, 14）のテストがある。オートで 1 戦闘が終わる。オート解除条件（CB-43）のテストがある。

## M4 街と全滅とセーブ

- `rules/town.ts`: 宿屋（TW-04、レベルアップと習得ダイス）、寺院（TW-07）、迷宮入口（TW-11）、SAN 回復（TW-02）、救済（TW-30〜32）。
- `rules/wipe.ts`: 潜行台帳（DG-40〜43）、全滅処理（TW-20〜27）、ペナルティ表の読み込み。
- 帰還の糸（DG-30）と徒歩帰還（DG-06）。
- `src/save/`: IndexedDB（SV-20〜23）、オートセーブ（SV-02）、タイトルのゲーム一覧（SV-12）、削除（SV-14）。
- 完了条件: 全滅 → ダイス → ペナルティ → 街、が実機で通る。TW-27 の不変条件のテストがある。どの画面でリロードしても続きから再開する。

## M5 性格・イベント・SAN

- `rules/events.ts`: 衝動判定（EV-10〜15）、制止判定（EV-20〜24）、結果の適用（EV-30〜34）。
- `data/events.json` の 2 つ（EV-50, 51）を迷宮に配置（DG-22）。
- 性格の恩恵（EV-40〜43）: `trapDetect`（DG-21）、`ambushAvoid`（CB-04）、`initiative`/`damage`（CB-11, 22）、オート戦闘の傾向（CB-44）。`chestQuality` と `hiddenTreasure` は後回し。
- SAN の閾値効果（CH-53, CB-45）と `fear` 耐性（CB-31）。
- 表示層: イベント画面（UI-55）、衝動の行動者の点滅。
- 完了条件: 2 つのイベントが実機で動き、慎重の制止判定が起き、出目が表示される。SAN が 0 になると行動不能になる。

## M6 仕上げ

- 演出スキップ・文字速度・入力モードの設定画面（UI-57）。
- PWA: `manifest.webmanifest`、Service Worker（vite-plugin-pwa 可）、ホーム画面追加の案内（SV-40）。
- 書き出し・読み込み（SV-30〜33）。
- `visibilitychange` での保存（SV-41）。
- 音（UI-06）は任意。入れるなら SE 3 つ（決定・被弾・全滅）だけ。
- 実機チェックリスト: iPhone（Safari タブ / ホーム画面追加）、Android（Chrome）で CLAUDE.md §9 の 1〜9 を確認し、結果を `docs/decisions.md` に記録。
  - あわせて、戦闘の対象の一覧（行が見える数より多いとき）で、半分見えている行のタップと、行に指を置いてからのスクロールの開始が意図どおりか（タップで選べる。スクロールの開始で一覧が勝手に動いたり、対象が選ばれたりしない）を確かめる。
  - あわせて、iOS Safari でバックグラウンドから戻った直後の保存が通るか（SV-23。IndexedDB の接続が切れていても次の保存で開き直し、「保存できません」の帯が出たままにならない）を確かめる。
- 完了条件: CLAUDE.md §9 がすべて通る。
